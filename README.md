# dasLabor23

Lern-App für die AP1-Prüfung Fachinformatiker Systemintegration: Karteikarten, Wissen zum Nachlesen, Lernspiele (Challenge, Match-Survival, Richtig oder Falsch, Terminal-Einsatz, SQL-Detektiv, Subnetz-Profi) und der Podcast „Netzwerktechnik zum Mitnehmen“.

## Online stellen mit GitHub Pages
1. Alle Dateien aus diesem Ordner in ein Repository hochladen (Hauptebene, nicht in einen Unterordner).
2. Im Repository: **Settings → Pages → Branch: main / (root) → Save**.
3. Nach ein bis zwei Minuten läuft die App unter `https://DEIN-NAME.github.io/REPO-NAME/`.

## Auf dem Handy installieren
- **iPhone:** Link in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
- **Android:** Link in Chrome öffnen → Menü ⋮ → „App installieren“ bzw. „Zum Startbildschirm hinzufügen“.

Der Lernstand wird nur auf dem jeweiligen Gerät gespeichert.
